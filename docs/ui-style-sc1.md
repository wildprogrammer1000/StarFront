# 스타프론트 UI 스타일 — 스타크래프트 1 콘솔

세로 웹 화면에 원작 콘솔의 **재질·색·위계**를 옮긴다. 4:3 하단 대시보드 배치 자체는 복제하지 않는다.

## 레퍼런스

| 출처 | 가져온 것 |
|------|-----------|
| 스타크래프트 매뉴얼 (1998) 인터페이스 | 자원, 초상, 상태, 커맨드 버튼, 미니맵, 메뉴. 단축키 글자만 다른 색 |
| Liquipedia — Minimap | 아군 녹, 적 적, 자원 청록. 시야 사각형은 밝은 테두리 |
| 패치 1.04 | 자원 숫자 색을 녹색으로 변경. 읽기 기준은 이 이후 |
| 종족 기본 콘솔 (Terran / Zerg / Protoss Default) | 강철+구리 립, 보라 생체, 금색 금속. 버튼은 각진 금속, 사용 가능 명령은 녹색 와이어 |

고유 로고, 초상화, 콘솔 텍스처, 전용 폰트는 쓰지 않는다. 금속 베벨과 녹색 와이어는 CSS로 재현한다.

## 세로 화면에서의 대응

| 원작 | 스타프론트 |
|------|------------|
| 메인 메뉴의 금속 버튼 더미 | 로비 하단 독. 종족 플레이트 + 금속 버튼 |
| 우상단 자원 (패널 없음, 아이콘+숫자) | 전투 HUD 우상단 |
| 하단 커맨드 카드의 각진 슬롯 | 생산 대기열, 건물 칩, 명령 버튼 |
| 금속 다이얼로그 | 결과·대기·에러의 커맨드 프레임 |
| 미니맵 좌하단 | MVP 범위 밖. 색 규칙만 예약 (아군 녹 / 적 적) |

## 색 역할

토큰은 `client/src/ui/tokens.css`.

| 역할 | 토큰 | 값 | 쓰는 곳 |
|------|------|----|---------|
| 배경 | `--bg` | `#05070a` | 스테이지 밖 |
| 금속 면 | `--plate` | 강철 그라데이션 | 버튼, 프레임 |
| 하이라이트 엣지 | `--metal-hi` | `#9aafbf` | 베벨 좌상 |
| 그림자 엣지 | `--metal-lo` | `#0c1218` | 베벨 우하, 패인 입력 |
| 형광 와이어 | `--phosphor` | `#7dff4a` | 슬롯 테두리, 포커스 |
| 형광 글자 | `--phosphor-text` | `#d6ffb0` | 버튼 라벨, 키커 |
| 본문 | `--ink` | `#e4f0dc` | 문장. 순수 형광은 본문에 쓰지 않음 |
| 자원 숫자 | `--res` | `#c6f56a` | 미네랄·가스·인구·타이머 |
| 미네랄 아이콘 | `--mineral` | `#49c8ee` | 아이콘만 |
| 가스 아이콘 | `--gas` | `#3dce55` | 에너지(가스) 아이콘만 |
| 체력 | `--hp` | `#3ad63a` | 아군 바. 그라데이션 없음 |
| 위험 | `--danger` | `#ff4a3a` | 적 체력, 인구 초과, 30초 이하 |
| 인간 | `--faction` | `#d08a45` | 구리 립 |
| 괴물 | `--faction` | `#c084f0` | 보라 립 |
| 외계인 | `--faction` | `#e6c15a` | 금색 립 |

종족 색은 콘솔 윗단 립, 선택 플레이트, 선택 칩에만 쓴다. 버튼 면 전체를 종족색으로 칠하지 않는다.

## 타이포

| 역할 | 폰트 | 용도 |
|------|------|------|
| 화면 전체 | Kostar | 워드마크, 버튼, 자원 숫자, 본문 |

파일은 `client/src/ui/fonts/Kostar.ttf`. Regular 한 굵기라 화면의 모든 웨이트가 이 파일을 쓴다.

## 컴포넌트

**돌출 금속** (`--bevel-raised` + `--plate`)  
버튼, 종족 플레이트, 커맨드 프레임, 방 목록. 모서리는 직각(`--radius: 0`).

**눌림** (`--bevel-pressed`)  
`:active`, `aria-pressed="true"`. 면이 안으로 들어가고 글자는 더 밝아진다.

**패임**  
입력, 스위치 트랙, 빈 생산 슬롯. 좌상 어둡고 우하가 금속 하이라이트.

**녹색 와이어**  
채워진 생산 슬롯, 선택된 칩, 포커스 링. 1px `--phosphor`.

**자원 스트립**  
배경·테두리 없음. 숫자 `--res`, 1px 검정 그림자. 인구 초과만 `--danger`.

**체력 바**  
검정 패임 위의 단색 바. 아군 녹, 적·저체력 적.

## 모션

- 눌림: 80ms, 이동 없음. 바운스·스케일 팝 없음.
- 화면 진입: 짧은 상승 (`sf-rise`).
- 매칭 링: 녹색 와이어 맥박만.

`prefers-reduced-motion`이면 애니메이션을 끈다.

## 금지

- 금색 그라데이션 주요 버튼, 앰버 코너 브래킷
- 둥근 iOS 스위치, 알약 배지, 카드 그림자 남발
- CRT 스캔라인, 보라 그라데이션 히어로
- 블리자드 로고·초상·콘솔 텍스처 복제
